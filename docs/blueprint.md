# **App Name**: AuraFlow

## Core Features:

- Intelligent Study Dashboard: A centralized glassmorphic hub providing daily task tracking, progress analytics, and real-time XP streaks to motivate consistent learning.
- Dynamic Schedule Tool: AI tool that takes subjects and exam dates to generate a personalized, high-performance study timetable automatically.
- Smart Document Synthesizer Tool: Upload PDFs or notes; the AI tool creates succinct summaries, flashcards, and chapter-wise breakdowns for quick revision.
- Academic Solver Chatbot: An AI-powered tutor that provides instant, step-by-step solutions to complex academic queries across any subject.
- Future Roadmap Tool: An AI engine that designs personalized career paths, recommending skills and courses based on a student's interests.
- ScholarHub & Alerts: Real-time alerts for scholarships and college applications with filtered eligibility tracking and cloud synchronization.
- Pro Resume & Sync Engine: An integrated AI-assisted resume builder and secure user profile system that syncs academic data across devices.

## Style Guidelines:

- Primary color: Vibrant Amethyst (#8C6AFF), chosen to evoke creative energy and focus for Gen Z users.
- Background color: Deep Obsidian Midnight (#0D0B12), providing a sophisticated high-contrast dark mode foundation.
- Accent color: Electric Cobalt (#4B78FF), offering a crisp contrast for call-to-actions and high-priority alerts.
- Font pairing: 'Space Grotesk' for tech-forward headers and 'Inter' for highly readable body text and metadata.
- Mobile-first, single-column dashboard utilizing glassmorphism panels with 16px corner radii and blur effects.
- Minimalist, duotone stroke icons with neon glows to indicate active states in the bottom navigation bar.
- Liquid smooth layout transitions using Framer Motion and pulse animations for gamified achievement pop-ups.
